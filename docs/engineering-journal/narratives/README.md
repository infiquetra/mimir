# Engineering Journal - Narratives

Self-contained, longer-form companion documents to the core journal files.

Use this folder for design walkthroughs, post-incident write-ups, research
notes, or implementation narratives that need to be readable cold by someone
who was not in the original chat.

Name files `YYYY-MM-DD-short-slug.md` and link them from the relevant
`LEARNINGS.md`, `DECISIONS.md`, or `QUEUED.md` entry.
